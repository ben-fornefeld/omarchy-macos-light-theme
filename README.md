# Omarchy macOS Light

Custom [Omarchy](https://github.com/basecamp/omarchy) desktop theme inspired by macOS light mode (includes `light.mode`).

## Install

```sh
omarchy-theme-install https://github.com/ben-fornefeld/omarchy-macos-light-theme.git
```

This installs to `~/.config/omarchy/themes/macos-light` and activates the theme.
